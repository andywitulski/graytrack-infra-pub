# Runbooks

Use these when something is broken or a time-critical procedure is due. Every recovery ends with
[Verify](disaster-recovery.md#verify-after-any-recovery).

| Runbook | Use when |
|---|---|
| [Disaster recovery](disaster-recovery.md) | A guest, node, tier, network or the whole site is lost |
| [Certificate rotation and compromise](certificate-rotation-and-compromise.md) | A key has leaked, a CA is expiring, or a person is locked out |
| [Incident response](incident-response.md) | An alert indicates possible compromise |
| [Patching](patching.md) | Applying OS and application updates |
