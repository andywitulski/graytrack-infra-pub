# NIST SP 800-207 zero trust mapping

Zero trust is a direction, not a state. This shows where the platform stands against each tenet (section 2.1).

| # | Tenet | Implementation | LC | Status |
|---|---|---|---|---|
| 1 | All data sources and computing services are resources | Every guest has its own identity, firewall and agent | LC-02, LC-09, LC-22 | Implemented |
| 2 | All communication is secured regardless of location | TLS on admin and platform; WireGuard. **HTTP behind the edge** | LC-06, LC-21 | Partial (G-09) |
| 3 | Access is granted per session | Short-lived certificates; application-level authorization | LC-07, LC-10 | Implemented |
| 4 | Access is determined by dynamic policy | Identity, group, device list, reputation. Device health is not assessed | LC-10, LC-11, LC-12 | Partial (G-08) |
| 5 | Integrity and posture of assets is monitored | SCA, FIM, vulnerability detection, EK pins. Not fed into access decisions | LC-13, LC-24, LC-25 | Partial |
| 6 | Authentication and authorization are dynamic and strictly enforced before access | MFA, forward auth, principals. **`lan_paths` trust source address** | LC-07, LC-11, LC-04 | Partial (G-16) |
| 7 | Collect information to improve security posture | SIEM with custom rules, audit-mode firewall data | LC-22, LC-23 | Implemented |

## Logical components

| 800-207 component | Here |
|---|---|
| Policy Engine | Authentik policies; OpenBao policies; step-ca authority policy |
| Policy Administrator | OpenTofu and Ansible, from code |
| Policy Enforcement Point | Caddy, sshd, guest firewall, gateway, Headscale ACLs |
| Data sources: CDM, threat intel | Wazuh and Fleet (not yet inputs to policy) |
| Data sources: ID management, PKI | Authentik, step-ca |
| Data sources: SIEM, activity logs | Wazuh |

**Approach:** Closest to the "enhanced identity governance" approach, with segmentation by micro-perimeter at the guest firewall once enforced.

**Next steps:** enforce device trust (G-08), eliminate address-based trust (G-16), encrypt internal hops (G-09), and use posture signals in access decisions.
